What the build planner is actually scoring

The planner compares each class against four player choices: run format, combat rhythm, risk tolerance, and experience level. Solo choices lean toward classes that can recover from mistakes. Squad choices give extra credit to control, information, and the ability to protect a teammate's escape path.

Combat rhythm changes the result. Burst damage lifts Shadowstrix and Sorcerer, control lifts Seer and Sorcerer, and frontline pressure lifts Mercenary and Withered Knight. Risk tolerance prevents the tool from recommending fragile classes to new players who asked for a safer route.

Use the result this way

If the top two classes are close, treat them as a tie and choose the role your squad lacks. If one class wins by a large margin, start there and then adjust gear around survivability, engage timing, or utility. The planner is a starting point, not official balance data.

Mistfall Hunter build planner FAQ

Is the Mistfall Hunter build planner an official calculator?

No. It is a fan-made planner that uses a transparent scoring model. Official Steam information is used for game facts, while class fit is editorial and should be corrected when reliable balance data appears.

Why does the planner ask for risk tolerance?

Risk tolerance changes what a good class means. A fragile burst class can be correct for an advanced player and wrong for a beginner who wants steadier extractions. The planner reduces high-risk recommendations when the selected profile asks for safer play.

Can I use the planner for duo runs?

Yes. Duo runs are treated as a middle point between solo independence and full squad utility. The result usually favors classes that can pressure fights without needing constant protection from two teammates.

What should I do after choosing a class?

Use the recommendation as a first direction, then read the class guide and test the role with your current gear. If two results are close, choose the class that fills the missing job in your party.
