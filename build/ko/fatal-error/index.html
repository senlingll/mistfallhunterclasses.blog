메뉴 전에 종료되거나 셰이더 준비 중 충돌하면 Steam과 Windows를 재시작하고, 파일을 확인하고, Steam 공식 사양과 PC를 비교한 뒤 Windows와 그래픽 드라이버를 업데이트하세요. 한 번에 하나만 바꿉니다.

Steam은 사양과 파일 확인의 공식 경로이고, 공식 사이트는 게임과 공식 미디어를 확인하는 출처입니다. 커뮤니티 글과 영상은 테스트할 가설이지 원인 증명이 아닙니다.

1. 시작, 셰이더, 로딩, 초대, 플레이 중 어디서 멈추는지와 Windows, GPU, 드라이버, RAM, 여유 공간, 오버레이를 기록합니다.

2. 게임과 Steam을 닫고 프로세스가 끝난 뒤 다시 실행합니다. 파일을 바꾸기 전에 Windows를 재시작하세요.

3. Steam에서 설치 파일을 확인합니다. 비공식 DLL이나 실행 파일로 교체하지 마세요.

4. Steam 표의 Windows 10 64비트, RAM 12GB, GTX 1060/RX 580급 최소 기준, DirectX 12, 광대역, 45GB 여유를 비교합니다. FPS 보장은 아닙니다.

5. Windows와 GPU 드라이버를 업데이트하고 오버레이를 닫은 뒤 보수적인 화면 설정으로 같은 조건에서 테스트합니다.

6. 메뉴 전 종료는 로컬 문제를 먼저, 메뉴 후 연결 종료는 서비스와 네트워크를 별도로 확인합니다.

셰이더에서 충돌하면 어떻게 하나요?

Windows와 GPU를 업데이트하고 오버레이를 닫고 공간과 파일을 확인합니다. 보장은 아닙니다.

확인한 공식 자료는 정의하지 않습니다. 전체 문구를 저장해 신고하세요.

재설치해야 하나요?

파일, 공간, 드라이버를 확인한 뒤 고려하세요. 계정이나 서버 문제는 고치지 못합니다.

커뮤니티 해결법을 써도 되나요?

환경과 날짜가 맞는 가설로만 보고 DLL, 실행 파일, 보안 해제를 피하세요.

Xbox나 PS5에도 적용되나요?

PC/Steam 실행 경로가 중심입니다. 콘솔은 플랫폼 지원을 사용하세요.

장비나 캐릭터가 사라지나요?

오류 화면만으로 손실을 증명할 수 없습니다. 재현되는 손실을 안전한 정보로 신고하세요.
