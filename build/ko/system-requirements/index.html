다음으로 CPU와 메모리를 확인합니다. GPU가 조건을 충족해도 CPU 부하가 큰 장면이나 여러 프로그램을 켠 상태에서는 여유가 부족할 수 있습니다. 12GB는 공식 최소치이므로 브라우저, Discord, 녹화 프로그램, 오버레이를 함께 사용한다면 16GB가 더 편합니다.

마지막으로 운영체제와 디스크를 확인하세요. 45GB만 딱 남기지 말고 패치, 셰이더 캐시, Windows 업데이트용 공간을 두세요. SSD는 로딩을 줄이는 데 도움을 주지만 최소 기준보다 낮은 CPU나 GPU를 권장 사양으로 바꾸지는 않습니다.
