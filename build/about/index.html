About Mistfall Hunter Classes

Learn how Mistfall Hunter Classes reviews public sources and keeps class guide recommendations transparent.

What this site does

Mistfall Hunter Classes is a fan-made class guide and planner for players comparing roles before they commit to a build. The site separates official facts from editorial recommendations and records when data is based on public store information or a transparent scoring model.

Editorial policy

Corrections are welcome. When verified patch notes, class values, or gameplay evidence changes the recommendations, the guide should be updated instead of preserving stale rankings.
