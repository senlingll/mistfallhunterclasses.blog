現在の答え：イベント交換を確認し、ショップの表示を優先する

2026年10月2日時点で、公式に確認しやすいゲーム内経路はSoul Harvestに参加してイベントトークンを獲得し、Mistchaser ShopでSoul Coinsへの交換を確認する方法です。Bellring GamesはSoul Harvest実装時、対象アイテムをSoul Coinsなどに交換できると案内しました。固定の獲得量、無制限の周回効率、常設の在庫までは公表していないため、現在のゲーム内に表示される数量と上限を確認してください。 公式告知で交換ルートは確認できますが、イベントの開催状況・在庫・価格は変わることがあります。現在のクライアントで確認してください。

ローンチ時には別々の報酬メールが2回あり、それぞれSoul Coins 500枚が案内されていました。アカウントが両方の対象で、期限内に受け取った場合は最大1,000枚です。両方とも期限は2026年9月1日00:00 UTCで、現在は受け取れません。Slumbering Contractは累計7日ログインで解放されますが、固定のSoul Coins総数を意味しません。古い推定値ではなく、現在の報酬トラックとタスクを確認してください。

Soul HarvestのトークンをMistchaser Shopで交換

開発元が説明する経路は2段階です。Soul Harvestに参加してイベント専用トークンを獲得し、Mistchaser Shopで対象アイテムと交換します。公式告知では店の報酬の一つとしてSoul Coinsが挙げられています。これはゲームプレイで得たトークンの交換であり、敵や通常の宝箱、脱出報酬からSoul Coinsが直接落ちるという意味ではありません。

同じ更新では、Soul CocoonsをRichieに持ち帰って確実な収益にする方法と、儀式の報酬を争う方法が説明されています。ただし、すべてのCocoonや儀式がSoul Coinsを直接支払うとは書かれていません。Richie、イベントトークン、ショップを別々の仕組みとして扱い、現行在庫と交換上限をゲームで確認してください。

ローンチ報酬メールは2回とも終了

Bellringの7月30日と8月1日の公式ローンチ報酬告知には、それぞれゲーム内メールでSoul Coins 500枚が記載されています。どちらも受取期限は2026年9月1日00:00 UTCでした。このガイドの確認日である10月2日には期限が過ぎており、今からメールボックスを開いても未受取分は復元されません。

2通は別々に数えてください。アカウントごとの対象条件と受取状況によっては、期限前に合計最大1,000枚が案内されていました。8月5日のマイルストーン報酬や8月15日の感謝メールを、さらに500枚の報酬と混同しないでください。古いページには第2弾を受取可能とする記載が残る場合がありますが、公表済み期限は終了しています。ほかの報酬は現在のパスとタスク画面で確認してください。第三者の合計推定は公式の一律支給額ではありません。

無料パスの解放条件はコイン量を保証しない

公式ローンチ時のよくある質問によると、シーズン1のSlumbering Contractは累計7日ログインすると解放できます。活動を続ければ次シーズンに更新できるという説明もありますが、この記述はSoul Coinsの一律の支給量を約束していません。現在のContract報酬を開き、各報酬名を確認してください。シーズンタスク、パス用トークン、コスメ、Soul Coinsは同じものではありません。

一部の非公式攻略はパス報酬のコイン数を推定していますが、現在の公式保証として一貫して示された合計ではありません。参考値とみなし、実際に受け取れる報酬はゲーム内の現在の表示を確認してください。

シーズン2の変更は今後の計画

Bellringは9月29日のコミュニティ回答で、Soul Harvestの周回負担を減らすためシーズン2に新しい季節モードと専用交換ショップを追加すると述べました。これは計画であり、稼働開始日、Soul Coinsの数量、最終商品一覧を記したパッチノートではありません。公式更新とショップがクライアントに登場するまでは、将来のショップを現在の入手経路に数えないでください。

Soul Coinsの入手方法：現在の経路を4点確認

報酬は更新で変わる可能性があり、公式告知もSoul Coinsの固定合計を示していません。パッチ後に戻ってきたときは、ゲーム内で次の項目を確認してください。現在の交換、期限切れメール、別通貨を混同せずに済みます。

1. 画面に表示された通貨名を確認

ゲーム内ショップまたは報酬画面を開き、アイテムの横にある通貨名を読みます。Soul Coins、Fate Coins、Moonlight Nectar、イベントトークン、パス用トークンは別の名称です。アイコンが似ていても残高を置き換えられる根拠にはなりません。

複数通貨が使える表示なら、ゲーム内購入画面の選択肢を確認してください。Fate CoinsがSoul Coinsに変換される、あるいは外部の価格表が自分の地域クライアントと一致すると決めつけないでください。

2. Soul HarvestとMistchaser Shopを確認

イベントの開催状況、必要なトークン、交換対象、残り在庫、更新やシーズンの上限を確認します。公式更新は交換経路を示し、後の修正ではショップ上限にも触れています。そのため、無制限に毎日購入できるとは案内できません。

チームのリスク許容度に合う出撃を選びましょう。Soul Harvestでは目標が競合し、PvPリスクもあります。Soul CocoonsをRichieに持ち帰る方法は儀式を争うより安全かもしれませんが、具体的な選択肢と報酬は開催中のイベント画面で確認してください。

3. パスとタスクを別々に見る

累計7日という条件はパスを解放する条件であり、全員が同じ通貨量を受け取るという説明ではありません。解放後、現在のContract画面で残りタスクと報酬アイコンを確認します。パストークン、Moonlight Nectar、コスメをSoul Coinsとして数えないでください。

パスやタスクが表示されない場合は、公式ニュースで開催期間を確認してください。過去のシーズンのスクリーンショットは以前の表示を記録できますが、現在の受け取り条件を証明しません。

4. 期限切れメールを除外し、更新後に再確認

2回のローンチ報酬メールはどちらも2026年9月1日に期限を迎えました。古いページが第2弾を受取可能と表示していても、各500枚の報酬を終了済みとして扱ってください。他の入手源を数える前に、現在のシーズンタスクとContractの報酬表示を確認しましょう。過去の推定値は個別アカウントの保証ではありません。

正確な数量で判断したいときは、ゲーム内画面と確認日を記録して公式告知と照らし合わせます。古いパスの推定値や他人のアカウントから推測するより確実です。

Soul Coins よくある質問

現在、Mistfall HunterでSoul Coinsを入手するには？

公式イベント更新では、出撃でSoul Harvestトークンを獲得し、Mistchaser Shopで対象アイテムを交換すると説明されています。報酬にSoul Coinsも含まれます。固定の支給量は告知されていないため、現在の在庫と上限をゲームで確認してください。

ローンチ時のSoul Coins 500枚メールをまだ受け取れますか？

いいえ。公式ローンチ報酬メールは別々に2回あり、それぞれSoul Coins 500枚が案内されましたが、どちらも2026年9月1日00:00 UTCに期限切れです。10月2日の確認時点では両方とも終了しています。最大1,000枚は両方の対象で期限内に受け取った場合に限られ、メールボックスから復元できません。

敵や宝箱からSoul Coinsが直接ドロップしますか？

公式Soul Harvest告知が説明しているのはMistchaser Shopで交換できるイベントトークンです。敵や通常の宝箱からSoul Coinsが必ず直接落ちるとは確認できません。新しいドロップ仕様は最新のパッチノートで確かめてください。

無料のSlumbering ContractでSoul Coinsを一定数もらえますか？

公式のよくある質問ではシーズン1パスが累計7日ログインで解放されると案内されていますが、その記述はSoul Coinsの一律合計を示しません。開催中の報酬トラックを確認し、未確認の合計を使わないでください。

Soul CoinsとFate Coinsは同じですか？

違います。別々の通貨名です。7月の公式告知はFate Coinsを別のコスメ購入通貨として扱い、Soul Harvest更新はSoul CoinsをMistchaser Shopの報酬に挙げています。購入画面の名称に従ってください。 Steamコミュニティの投稿では決済時にFate Coinsで不足分を補えると報告されていますが、別通貨です。購入画面で実際の選択肢を確認してください。

Soul Coinsはシーズン2へ引き継がれますか？

9月29日の開発元回答はシーズン2の交換ショップ計画を告知していますが、Soul Coinsの引き継ぎは決めていません。使用や保管の前に最終的なリセット規則と現行アイテム説明を待ちましょう。
