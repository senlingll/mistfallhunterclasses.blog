Perguntas frequentes do planejador

Qual classe é melhor para iniciantes?

Mercenary é o começo mais seguro; Withered Knight também ajuda em grupo.

Shadowstrix é boa solo?

Sim, com timing de emboscada e recuo, mas pune mais erros.

Todo grupo precisa de Seer?

Não, mas Seer vale muito quando falta informação.

O planejador é preciso?

É um modelo fan-made útil e deve seguir dados verificados.
